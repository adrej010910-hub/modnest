# MODNEST — каталог игровых модификаций

Статический адаптивный сайт, готовый к публикации на Vercel.

## Запуск локально
Откройте `index.html` в браузере или запустите `python -m http.server 8000` в этой папке.

## Публикация на Vercel
Импортируйте репозиторий GitHub в Vercel. Framework Preset: Other, Build Command: пусто, Output Directory: `.`.

## Реализовано
- Главная страница с навигацией, hero-витриной, статистикой, блоком преимуществ и CTA.
- Каталог демонстрационных модификаций, поиск, категории и сортировка.
- Добавление в локальную коллекцию и избранное (в памяти вкладки).
- Модальные окна для демонстрации входа/регистрации.
- Адаптивная мобильная версия.

## Пока не подключено
Авторизация, серверная база данных, реальные файлы модов, скачивание и установка. Все позиции каталога — демонстрационные данные. Проект самостоятельный, не копирует серверную часть и контент ReduxLab.
